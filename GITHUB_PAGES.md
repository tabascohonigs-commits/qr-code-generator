# GitHub Pages Configuration
# This file can be deleted after GitHub Pages is enabled

# To enable GitHub Pages:
# 1. Go to your repository on GitHub
# 2. Click Settings > Pages
# 3. Under "Build and deployment", select:
#    - Source: Deploy from a branch
#    - Branch: main
#    - Folder: / (root)
# 4. Click Save
# 5. Your site will be live at: https://tabascohonigs-commits.github.io/qr-code-generator

# The workflow in .github/workflows/gh-pages.yml will handle the automatic deployment
